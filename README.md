# ARFace-EyeTracker

FaceID (TrueDepth) 搭載の iPhone を空間センサーとして利用し、PC 上にリアルタイムで視線ポインターを描画するアイトラッキングシステムです。

※ 本プロジェクトは現在テスト・検証段階（PoC）のプロトタイプです。
※ 実装の多くは AI コーディング(Copilot, Gemini)を活用して作成されています。

---

## ソフトウェア概要

- iPhone 側 (iOS / Swift):
  TrueDepth カメラで顔の 3D 位置姿勢、両目の視線ベクトル、および全 52 種類の ARKit BlendShapes 生データを取得し、ローカルネットワーク上の PC へ UDP で送信します。
- PC 側 (Windows / Python):
  受信した生データをもとに幾何計算、9点キャリブレーション、One-Euro Filter によるジッター除去を行い、画面最前面に完全透過の視線 HUD を描画します。

---

## 技術選定の理由

1. iPhone TrueDepth (ARKit) の採用:
   通常の Web カメラ＋画像認識方式と異なり、赤外線ドットプロジェクタによる専用深度センサーを使用するため、暗所や部屋の照明変化、画面の照り返しの影響を受けずに高精度な 3D 視線・頭部データを取得できます。

2. UDP プロトコル:
   TCP のような再送制御を行わず、パケット到着の即時性を最優先することで、競技ゲーム等でも実用に耐えうる極小の通信遅延を実現しています。

3. Python + PyQt (PC クライアント):
   Win32 API と組み合わせることで、ゲームのフルスクリーンプレイを妨げない完全透過・クリック透過のオーバーレイを容易に制御でき、フィルタや幾何計算の調整も柔軟に行えるためです。

4. XcodeGen + GitHub Actions:
   Windows 開発環境のみで完結させるため、クラウド上の無料 macOS ランナーでプロジェクト生成と IPA パッケージングを自動化しています。
